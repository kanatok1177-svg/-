# Reboot 🌱 — 7日間ドーパミンデトックス

たった1週間で、スマホ・SNS・ショート動画への「ドーパミン中毒」から抜け出すための実践アプリです。
ビルド不要の静的サイト（HTML / CSS / Vanilla JS）で、ブラウザだけで動作します。

## 特徴

- **7日間プログラム** — 「ベースライン測定」「環境デザイン（選択アーキテクチャ）」「自然な報酬」「対抗過程理論に基づくプチ断食」「if-thenプランニング」「対面のつながり」「再発防止モデル」の7テーマ。各日で異なる行動科学・心理学の知見を土台にした3つのミッションと豆知識つき。
- **SOS 衝動サーフィン** — スマホを触りたい衝動が来たら90秒の呼吸タイマーで待つ機能。衝動の波はだいたい90秒で過ぎ去るという知見に基づいています。
- **進捗トラッキング** — 達成日数・連続達成日数・乗り越えた衝動の回数をリング/バッジで可視化。
- **記録（ジャーナル）** — 日ごとの振り返りを記録し、後から読み返せます。
- **完全ローカル保存** — すべてのデータは `localStorage` に保存され、外部サーバーには送信されません。

## 使い方

ビルドツール不要です。`index.html` をブラウザで開くだけで動作します。

```bash
# ローカルサーバーで確認する場合（任意）
python3 -m http.server 8080
# → http://localhost:8080 を開く
```

GitHub Pages などの静的ホスティングにそのままデプロイすることもできます。

## ファイル構成

```
index.html      # 画面構造（ホーム / プログラム / SOS / 記録の4タブ）
css/style.css   # スタイル（ダーク・落ち着いたトーンのUI）
js/app.js       # 状態管理・7日間プログラムのデータ・タイマーロジック
```

## データの仕組み

- 状態はすべて `localStorage`（キー: `reboot_dopamine_detox_v1`）に保存されます。
- 「リセット」ボタンで全記録を初期化できます。
- サーバー通信は一切行いません（オフラインでも動作します）。
